# TL;DR

Added `src/api/` and `src/collaboration/` layers to the existing frontend without breaking the existing rendering architecture.

## Changes

**New files:**
- `src/api/client.ts` — Generic HTTP client with configurable base URL
- `src/api/documentApi.ts` — Typed document CRUD functions
- `src/collaboration/CollaborationClient.ts` — WebSocket client with auto-reconnect and room-based messaging

**Kept intact:**
- `models/` — Observable model pattern, object interfaces, factory
- `commands/` — Command pattern with undo/redo stack
- `views/` — React rendering layer
- `viewModels/` — React context bridge
