# TL;DR

pswp-graphic-tool is a purely client-side React/TypeScript vector graphics editor. No backend at all — all state is in-memory. The user wants a Java Spring backend added and the frontend restructured with docs.

## Current Architecture

**TypeScript frontend (Vite + React 19):**
- `models/` — `GraphicEditorModel` (Observable pattern) owns an array of `GraphicObjectInterface` objects. Supports add/remove/update/move/group/ungroup/reorder.
- `commands/` — `Command` base class + `CommandManager` for undo/redo. Commands snapshot model state before executing.
- `viewModels/` — React ContextProvider that wraps commands + React state for selected IDs.
- `views/` — Canvas, Shape dispatcher, shape renderers (Rectangle, Ellipse, Line, Text, Image, Group), Handlers (resize/rotate), PropertiesPanel, Layers, ToolBar.
- `hooks/` — useSubscribe (model → React bridge via custom observer), useDrag, useUpdateView.
- `utils/` — walk (recursive tree update), search (recursive ID lookup), bounding box helpers.

Strengths: Observer pattern, Command pattern, clean shape rendering layer.
Weaknesses: No persistence, no collaboration, some coupling between ContextProvider and commands.

## Rewrite Plan

**Backend (Java Spring Boot):** REST API for document CRUD + WebSocket for real-time collaboration.
**Frontend (TypeScript):** Add API layer + collaboration client, keep existing rendering clean.
**Docs:** Fully documented code, README, API spec.
