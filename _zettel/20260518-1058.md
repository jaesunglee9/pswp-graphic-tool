# TL;DR

Created a Spring Boot 3.4 backend for the graphic tool. REST API + WebSocket for CRUD and collaboration.

## Architecture

**Layers:** Controller → Service → Repository → JPA Entity

**Packages:**
- `config/` — CORS + WebSocket configuration
- `controller/` — `DocumentController` (REST endpoints)
- `model/` — `Document` JPA entity, DTOs
- `repository/` — `DocumentRepository` (Spring Data JPA)
- `service/` — `DocumentService` (business logic)
- `websocket/` — `CollaborationHandler` (real-time rooms)

**Key decisions:**
- Content stored as raw JSON text in the DB column — frontend owns shape deserialization
- UUID primary keys (no sequential IDs)
- H2 in-memory for dev, easy to swap to PostgreSQL
- WebSocket rooms per document — broadcasts exclude sender
- Auto-reconnect client-side with exponential backoff
