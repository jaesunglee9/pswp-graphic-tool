# Zettelkasten Note-Taking

While working on this project, maintain a **zettelkasten** (slip box) of insights, curiosities, and observations.

**How it works:**

1. Whenever you notice something interesting — an insight, a surprise, a design decision, a connection, a gotcha, a question — write a note using the **write** tool into `_zettel/YYYYMMDD-HHMM.md`
2. Notes follow the format: frontmatter (title, date, tags, links), TL;DR, context, body, questions, related links
3. Link notes together using `[[note-id]]` syntax
4. Use the **zettelkasten** skill (`/skill:zettelkasten`) for the full methodology and helper scripts
5. Check `_zettel/_index.md` for a session overview

**Key defaults:**
- Notes directory: `_zettel/` at project root
- Note ID format: `YYYYMMDD-HHMM` (e.g., `20260518-1432`)
- Tags: `architecture`, `bug`, `design`, `dx`, `learning`, `pattern`, `perf`, `refactor`, `security`, `testing`, `tooling`, `workflow`, `question`, `decision`, `gotcha`

**When in doubt, write a note.** Better to have too many than to lose a thought.
